# Soya stickers

1. `soya-good-morning-he.webp`, `soya-good-morning-en.webp`: animated WhatsApp stickers (512×512, transparent, under 500 KB).
2. `soya-good-morning-he.gif`, `soya-good-morning-en.gif`: the same animation as GIFs, to send as a normal message.
3. `soya-good-morning-*-still.webp`: still versions. `tray-96.png`: the pack icon.

Soya is drawn from annabelle-games (`soya.html`). Made by Soycatory.
